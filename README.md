# تطبيق رغيف — مشروع Android

مشروع Android Studio أولي مستقل باسم **Raghif**، معدّ ليُرفع إلى مستودع GitHub جديد ليقوم GitHub Actions ببناء APK.

## البناء عبر GitHub Actions
1. أنشئ مستودعًا جديدًا باسم `Raghif-Android` على حساب GitHub.
2. ارفع محتويات هذا المجلد إلى جذر المستودع (وليس المجلد الحاوي له).
3. افتح تبويب **Actions**، وفعّل Actions إن طلب GitHub ذلك.
4. اختر **Build Raghif APK** ثم **Run workflow**.
5. عند نجاح التشغيل، افتح تفاصيل التشغيل وحمّل `Raghif-Debug-APK` أو `Raghif-Release-APK` من Artifacts.

## ملاحظات مهمة
- الحزمة `com.raghif.app` واسم التطبيق الظاهر `رغيف`.
- قاعدة البيانات محلية باستخدام Room.
- التقرير المالي مخصص لعرض بندي **الإيراد** و**المباع آجل** فقط.
- لا يحتوي المشروع على مفاتيح توقيع إصدار Release؛ لذلك ملف Release الناتج غير موقّع للنشر في Google Play.
- هذه حزمة تنفيذ أولية تحتاج مراجعة واختبارًا على جهاز فعلي قبل اعتمادها نهائيًا. لم يتم التحقق من نجاح البناء في بيئة هذه المحادثة.
- واجهة القفل التلقائي والبصمة والوضع الليلي وصوت النقر تحتاج استكمال ربطها بسلوك Android الفعلي قبل اعتبار هذه المتطلبات مكتملة.
