# مواصفات واجهات تطبيق رغيف — المرجع البصري الأصلي

المرجع المعتمد: الصور التسع المرفقة من صاحب المشروع بتاريخ 11 نوفمبر 2026.

## ثوابت لا يجوز تغييرها

- المعادلات المالية والإنتاجية في ReportMath.kt تبقى مطابقة تمامًا للنسخة السابقة.
- المفتاح المنطقي للسجل هو (bakeryId + date): سجل واحد لكل مخبز في كل يوم، دون التأثير على تواريخ أخرى.
- اللغة العربية والاتجاه من اليمين إلى اليسار RTL.
- نفس الهوية الأصلية: بني داكن، برتقالي محروق، ذهبي، كريمي وعاجي، وشعار رغيف وسنابل القمح والخبز والفرن.
- الأرقام الظاهرة في صور التصميم بيانات مثال فقط؛ التطبيق يعرض سجلاته الحقيقية، لا أرقامًا ثابتة.
- لا تعديل لمخطط قاعدة البيانات في هذه الدفعة، ولا مساس بالبيانات الحالية.

## الشاشات التسع المرجعية

1. اختيار المخبز: الصورة الأصلية أعلى الشاشة، بطاقات كريمية ذات إطار ذهبي تتضمن الاسم والعنوان والهاتف، دخول المخبز وإضافة مخبز.
2. لوحة المخبز: تاريخ اليوم، ست بطاقات للإدخال والإحصاءات والتقارير المالية والبحث والسجلات السابقة وتصدير PDF، وآخر سجل محفوظ.
3. إدخال البيانات: تقويم اليوم الافتراضي، أقسام الإنتاج والمبيعات والمصروفات، النتائج المحسوبة تلقائيًا، حفظ مستقل لكل تاريخ.
4. البحث: حقل بحث، فلاتر المخبز والفترة، بطاقات نتائج متعددة الأعمدة وفتح التفاصيل.
5. الإحصاءات: فترة البحث، أربع بطاقات مؤشرات، رسوم الإنتاج والإيراد الفعلي، أعلى النتائج.
6. التقرير المالي: المخبز والفترة، المؤشرات والرسوم وأعلى الإيرادات وتصدير PDF.
7. تصدير PDF: تقرير يومي أو مالي، التقويم، المعاينة والحفظ والمشاركة والطباعة.
8. ملف PDF: ترويسة هوية رغيف الأصلية، جدول عربي RTL، الفترة والإجماليات وترقيم الصفحات.
9. الإعدادات: الوضع الليلي، العربية، التحديث المحلي، صوت النقر، النسخ الاحتياطي والاستعادة، محو البيانات بتأكيد، حول التطبيق.

## الأصول الأصلية المضافة للمشروع

- app/src/main/res/drawable-nodpi/raghif_original_header.webp — صورة مرجعية للقمح والفرن والشعار.
- app/src/main/res/drawable-nodpi/raghif_logo_icon.webp — الأيقونة الأصلية المقتصّة من المرجع.
- يستخدم مشغّل Android والصفحات وتقارير PDF هذه الأصول بدل شعار بديل.

## اختبارات الاعتماد

- إنشاء سجل بتاريخ سابق لا يغيّر سجل اليوم ولا معرفه.
- اختيار تاريخ مسجل يحمل بيانات ذلك اليوم فقط.
- التاريخ الجديد غير المسجل يظهر حقولًا فارغة.
- لا بيانات مالية ثابتة في الواجهات أو PDF.
- التقويم، زر الرجوع، الصوت والحفظ والمشاركة والطباعة تعمل على هاتف أندرويد.
- اختبارات GitHub Actions وبناء APK ناجحة.
- فحص مطابقة أحجام وتفاصيل الواجهات التسع على أجهزة فعلية قبل الاعتماد النهائي.
